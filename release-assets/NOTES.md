## Pokémon Esmeralda PT-BR — Emerald3DS (tradução completa)

Port nativo para Nintendo 3DS (tela dupla, interface de toque e mundo voxel 3D opcional) com a tradução PT-BR completa de **Carlos Mozart (AllGenWiki)** (~14.300 textos), compilada do upstream `ZallaxDev/emerald-3ds` (`dev`) com `--port-lang pt_br`.

### Conteúdo

- `Emerald3DS.3dsx`
- `Emerald3DS.smdh`
- `emerald3ds.pak`
- `Emerald3DS-Forwarder.cia` (atalho opcional na home)
- `LEIA-ME.txt`
- `SHA256SUMS.txt`

### Instalar

1. Copie para o SD:

   ```
   SD:/3ds/emerald3ds/Emerald3DS.3dsx
   SD:/3ds/emerald3ds/Emerald3DS.smdh
   SD:/3ds/emerald3ds/emerald3ds.pak
   ```

2. Garanta `SD:/3ds/dspfirm.cdc` (som).
3. Homebrew Launcher → **Emerald 3DS**.
4. Save: `SD:/3ds/emerald3ds/emerald3ds.sav` (compatível).

Sempre use o `.3dsx` e o `.pak` do mesmo pacote.

### Tradução e correções

- Textos do jogo e interface da tela de baixo em PT-BR.
- POKéDEX: tela de registro de novo POKéMON sem corte de texto.
- Golpes de campo em tela toda (SURF/CUT/FLY) cobrindo os 400 px.
- Cura no CENTRO POKéMON alinhada ao mapa.
